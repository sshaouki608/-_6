# رفيق — النسخة الأولية

نسخة أولية لتطبيق أندرويد مبني بـ Flutter، بواجهة عربية وبيانات محلية.

## ما الموجود الآن؟
- إضافة المهام والملاحظات.
- وضع علامة على المهمة عند إنجازها.
- فلترة العناصر.
- حذف العناصر.
- حفظ البيانات محليًا باستخدام SharedPreferences.
- لا يوجد حساب مستخدم أو خادم مطلوب لتشغيل هذه الميزات.

## طريقة الاستخدام
1. أنشئ مشروع Flutter جديدًا باسم `rafiq_offline`.
2. استبدل `pubspec.yaml` و`lib/main.dart` بالملفين الموجودين هنا.
3. شغّل `flutter pub get` أثناء الاتصال بالإنترنت أول مرة لتنزيل الحزمة.
4. اختبر التطبيق، ثم نفّذ `flutter build apk --release`.
5. عادةً ينتج ملف APK في `build/app/outputs/flutter-apk/app-release.apk`.

هذه الحزمة تحتوي ملفات المصدر الأساسية فقط وليست APK جاهزًا للتثبيت؛ يلزم وجود بيئة بناء Flutter/Android لإنتاج APK.
